## 1. 수집하는 개인정보

본 앱은 사용자의 개인정보를 수집하거나 외부 서버로 전송하지 않습니다.

## 3. 데이터 저장

모든 데이터는 사용자의 기기 내부에만 저장됩니다.

앱을 삭제하면 저장된 데이터도 함께 삭제됩니다.

본 앱은 사용자의 개인정보를 제3자에게 제공하거나 판매하지 않습니다.
