ShiftBell (교대종) 개인정보처리방침

본 개인정보처리방침은 ShiftBell(교대종) 앱(이하 "앱")에 적용되며,
Play 스토어 개발자 lowvibe07이 제공하는 앱의 개인정보 처리 방침을 설명합니다.

1. 수집하는 정보

본 앱은 회원가입을 위해 이름, 이메일, 전화번호 등의 개인정보를 요구하지 않습니다.

앱의 기본적인 근무표 및 알람 기능은 사용자의 기기 내부에 데이터를 저장하여 이용할 수 있습니다.

다만, 근무표 공유 기능을 이용하는 경우, 다른 사용자에게 근무 스케줄을 공유하기 위해 사용자가 공유를 선택한 근무 스케줄 및 교대근무 관련 정보가 Firebase Cloud Firestore 서버에 저장될 수 있습니다.

공유 기능 이용 시 Firebase의 익명 인증을 사용하며, 이를 위해 별도의 개인정보를 입력하지 않고 익명의 사용자 식별자(UID) 가 생성될 수 있습니다.

2. 수집·저장되는 정보의 범위

공유 기능을 이용할 경우 다음과 같은 정보가 서버에 저장될 수 있습니다.

사용자가 공유를 선택한 근무 스케줄
교대근무 패턴 및 근무일 관련 정보
공유 기능 이용을 위한 익명 사용자 식별자(UID)
공유 기능의 정상적인 제공을 위해 필요한 정보

앱의 일반적인 근무표 및 알람 데이터는 기본적으로 사용자의 기기에 저장됩니다.

3. 앱 권한
다른 앱 위에 표시 권한: 다른 앱 사용 중에도 알람 화면을 표시하기 위해 사용됩니다.
알림 권한: 알람 및 사전 알림을 제공하기 위해 사용됩니다.
4. 데이터 저장 및 삭제

공유 기능을 이용하지 않는 경우, 근무 스케줄 및 알람 등의 데이터는 사용자의 기기 내부에 저장됩니다.

공유 기능을 이용하는 경우, 공유를 위해 선택한 근무 스케줄 정보가 Firebase Cloud Firestore에 저장됩니다.

사용자는 앱에서 제공하는 공유 기능을 통해 생성된 공유 정보를 삭제할 수 있으며, 앱을 삭제하면 기기 내부에 저장된 앱 데이터는 삭제됩니다.

단, 서버에 저장된 공유 정보는 앱의 공유 기능에서 별도로 관리될 수 있습니다.

5. 제3자 서비스

본 앱은 공유 기능 및 익명 인증을 제공하기 위해 Google Firebase 서비스를 사용합니다.

Firebase를 통해 공유 기능에 필요한 데이터가 서버에 저장될 수 있으며, Firebase의 서비스 이용 및 데이터 처리에 관한 사항은 Google의 관련 정책에 따릅니다.

6. 제3자 제공 및 판매

본 앱은 사용자의 개인정보를 제3자에게 판매하지 않습니다.

공유 기능을 통해 사용자가 직접 공유하기로 선택한 근무 스케줄은 해당 공유 기능을 이용하는 다른 사용자에게 제공될 수 있습니다.
